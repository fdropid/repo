# เอกสารสำหรับโปรเจกต์ของฉัน

ยินดีต้อนรับสู่เอกสารโปรเจกต์ — นี่คือตัวอย่างหน้าเริ่มต้น

วิธีใช้งาน
- แก้ไขไฟล์นี้ตามเนื้อหาที่ต้องการ
- เพิ่มหน้าใหม่ในโฟลเดอร์ `docs/` เช่น `getting-started.md`, `api.md`

ลิงก์ตัวอย่าง
- หน้าแรก: `index.md`
- ปรับแต่งธีมหรือใช้ static site generator (เช่น MkDocs หรือ Docusaurus) หากต้องการไซต์ที่ซับซ้อนขึ้น
